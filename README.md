# El G — Sistema POS

Sistema de punto de venta personalizado para **El G**, tienda de TCG, juegos de mesa y comidas rápidas. Desarrollado en Python con Tkinter y SQLite.

## Tecnologías

- Python 3.10+
- Tkinter (interfaz gráfica)
- SQLite (base de datos local)

## Módulos

- Ventas (tienda y cocina)
- Inventario y productos
- Comidas rápidas, combos e insumos
- Caja (apertura, cierre, denominaciones COP)
- Proveedores y pedidos
- Reportes y KPIs
- Autenticación con roles (admin / vendedor)

## Instalación

```bash
git clone https://github.com/TU_USUARIO/TU_REPO.git
cd TU_REPO
python -m venv venv
venv\Scripts\activate   # Windows
python database.py      # inicializa la base de datos
python main.py          # lanza la aplicación
```
